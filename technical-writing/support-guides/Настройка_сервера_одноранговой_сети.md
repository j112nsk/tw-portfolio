# Настройка сервера одноранговой сети

## Перед началом работы:

- Все действия выполняются от имени локального администратора;

- На сервере должен быть установлен пакет Microsoft Visual C++ Redistributable (x86) для работы MuzzleServer;

- Убедитесь, что сервер имеет статический IP-адрес в локальной сети;

- Клиентские компьютеры должны иметь доступ к серверу по протоколу SMB (сетевое окружение);

## Серверная часть

1. Установка СБИС++

Установите **СБИС++ 2.4** в папку `C:\Сбис++ Сервер`. 
Если программа уже установлена, скопируйте её папку в `C:\Сбис++ Сервер`;

2.	Запустите программу файлом **sbis.exe**
>При первом запуске программа потребует создать налогоплательщика при помощи Мастера. Если СБИС++ уже был установлен, и налогоплательщик в нем был заведен, пропустите этот пункт;

3.	Скопируйте файл **fsynchron.exe** в каталог `C:\Сбис++ Сервер`

4.	Разделение базы и модулей

Переместите вложенную папку **db** в корень `C:\Сбис++ Сервер`. Оставшуюся папку с исполняемыми файлами переименуйте в **Modules**. В итоге в `C:\Сбис++ Сервер` будут две папки: **db** и **Modules**;

5.	Настройка сетевого доступа к модулям

Откройте общий доступ к папке **Modules**. Для группы «Все» установите права «Чтение». Если вы планируете обновлять модули с клиентов, добавьте для учётной записи администратора право «Изменение». Права на папку **db** не открывайте;

6.	Установка и настройка сервера БД

Установите «**СБИС Сервер одноранговой сети**» в стандартную папку. При запуске укажите путь к базе: `C:\Сбис++ Сервер\db`. Остальные параметры оставьте по умолчанию.
После установки в системном трее появится значок. Цвет значка: голубой — сервер работает ![alt text](images/image.png), серый — ошибка. Проверьте:
- правильность пути к db,
- доступность порта 7777 (можно проверить командой `netstat -an | find "7777"`). При необходимости порт можно изменить в настройках сервера, но тогда не забудьте учесть это в клиентских настройках;

>Если порт 7777 не отображается в списке прослушиваемых, проверьте настройки брандмауэра Windows — создайте входящее правило для TCP-порта 7777.


## Клиентская часть
>*Если вы планируете запускать программу с самого сервера, то для её корректной работы необходимо создать отдельный каталог с программой-клиентом, как показано в инструкции ниже*

1.	Подготовка клиентского каталога

На клиентском компьютере создайте папку, например, `C:\Сбис++ Клиент`. Скопируйте в неё файлы **fsynchro.exe, fsynchro.ini, sbis.ini** (эталонные версии этих файлов можно взять с сервера из папки Modules);

2.	Настройка синхронизации (fsynchro.ini)

Откройте файл **fsynchro.ini** в текстовом редакторе. Приведите его к виду:

`КаталогИсточник=\\IP_сервера\Modules`

`КаталогПриемник=C:\Сбис++ Клиент`

(где IP_сервера — реальный IP или сетевое имя сервера);

3.	Настройка подключения к БД (sbis.ini)

В файле **sbis.ini** укажите:

`База данных=sbis-net:\\IP_сервера:7777`

`КонфигСетевойКлиент=\\IP_сервера\Modules`

`КонфигСинхронизация=\\IP_сервера\Modules\fsynchro.exe`

Сохраните файл;

4.	Первый запуск и синхронизация

Запустите **fsynchro.exe** (в дальнейшем используйте этот файл для старта СБИС). При первом запуске программа скопирует все необходимые модули из сетевой папки в локальный каталог клиента и автоматически запустит СБИС. Если этого не произошло, проверьте доступность сетевого пути и права на папку **Modules**.

## Возможные проблемы

- Значок Сервера в трее серый — проверьте, не занят ли порт 7777 другой программой, или не указан ли неверный путь к папке db.

- Ошибка «Не удалось загрузить библиотеку» — установите Microsoft Visual C++ Redistributable 2015–2022 (x86) на клиентскую машину.

- Синхронизация не идёт — убедитесь, что клиент имеет доступ к `\\IP_сервера\Modules` (проверьте через проводник).

- СБИС запускается, но пишет «нет доступа к базе» — проверьте, что в sbis.ini верно указан IP и порт, и что брандмауэр на сервере разрешает входящие соединения на этот порт.
