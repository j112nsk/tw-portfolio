# Установка корневых сертификатов центров сертификации (ЦС)

## Перед началом:

- Выполняйте действия от имени локального администратора.

- Файл сертификата должен иметь расширение .cer и быть получен из надёжного источника.

- Установка непроверенного корневого сертификата может снизить безопасность системы — устанавливайте только те сертификаты, которые рекомендованы вашим администратором или официальным центром сертификации.

## Порядок действий: 

1.	Дважды щелкните левой кнопкой мыши по файлу сертификата (`.cer`), чтобы открыть его.

2. В открывшемся окне нажмите кнопку «**Установить сертификат...**».

![alt text](images/image-2.png)

3.	В мастере импорта сертификатов нажмите «**Далее**».

![alt text](images/image-3.png)

4.	Выберите переключатель «**Поместить все сертификаты в следующее хранилище**» и нажмите кнопку «**Обзор**».

![alt text](images/image-4.png)

5.	В списке хранилищ выберите «**Доверенные корневые центры сертификации**» и нажмите «**ОК**».

![alt text](images/image-5.png)

6.	Нажмите «**Далее**», затем «**Готово**».

![alt text](images/image-6.png)

![alt text](images/image-7.png)

7. Если появится окно «**Предупреждение безопасности**», внимательно прочитайте его содержимое. Если вы доверяете источнику сертификата, нажмите «**Да**», чтобы продолжить.

![alt text](images/image-8.png)

8.	После завершения импорта нажмите «**ОК**» в информационном окне.

![alt text](images/image-9.png)

>Повторите эти шаги для каждого файла сертификата, который необходимо установить.
