# «Система управления внутренними регламентами»

**Суть проекта:** Спроектировать простой бэкенд для хранения и версионирования инструкций. Без реального кода, но с полной аналитикой.

**Что сделать:**

- Use Case диаграмму (кто и как создаёт/утверждает/ищет инструкцию).

- Модель данных (PostgreSQL: documents, versions, tags, feedback, views).

- Нефункциональные требования:

   - Время поиска по 500+ документам < 1 с.

   - Ролевая модель: автор, редактор, читатель.

- Макет UI в Draw.io (Wireframe списка документов и карточки редактирования).

- Пример acceptance test для кейса: «Пользователь находит инструкцию по КЭП за 2 клика».

**Артефакты:** ERD, Use Case, НФТ, wireframes, тест-кейс.
