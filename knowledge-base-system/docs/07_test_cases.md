# Тест-кейсы

**1. TC-01:** Редактор создаёт новую версию утверждённого документа

| Шаг | Действие                                                                      | Ожидаемый результат                                                        |   |
|-----|-------------------------------------------------------------------------------|----------------------------------------------------------------------------|---|
| 1   | Авторизоваться как пользователь с ролью «редактор»                            | Успешный вход                                                              |   |
| 2   | Открыть существующий документ (например, «Инструкция по КЭП», версия 1.0)     | Отображается версия 1.0, кнопка «Редактировать» активна                    |   |
| 3   | Нажать «Редактировать», изменить содержание и нажать «Сохранить новую версию» | Система создаёт версию 1.1 со статусом «review»                            |   |
| 4   | Открыть историю версий                                                        | Видны версии 1.0 и 1.1, для 1.1 статус «review»                            |   |
| 5   | Подтвердить версию 1.1 (нажав «Approve»)                                      | Статус меняется на «approved», current_version_id документа становится 1.1 |   |
| 6   | Выйти и зайти как читатель                                                    | Видна новая версия 1.1                                                     |   |

**2. TC-02:** Читатель пытается редактировать → кнопки нет, прямой запрос на edit возвращает 403.

**3. TC-03:** Поиск документа по ключевому слову (US-01)

| Шаг | Действие                                                 | Ожидаемый результат                                                      |   |
|-----|----------------------------------------------------------|--------------------------------------------------------------------------|---|
| 1   | Авторизоваться как любой пользователь (например, reader) | Успешный вход                                                            |   |
| 2   | На главной странице ввести в поле поиска слово «КЭП»     | Появляется список документов, содержащих «КЭП» в названии или содержимом |   |
| 3   | Проверить время отклика                                  | Результаты отображаются менее чем за 1 секунду                           |   |
| 4   | Кликнуть по первому результату                           | Открывается карточка документа с полным содержимым                       |   |
|     |                                                          |                                                                          |   |

Негативный вариант TC-03a:

| Шаг | Действие                                           | Ожидаемый результат                                       |   |
|-----|----------------------------------------------------|-----------------------------------------------------------|---|
| 1   | Ввести несуществующее слово | Отображается сообщение «Ничего не найдено», пустой список |   |
|     |                                                    |                                                           |   |

**4. TC-04:** Ролевое ограничение – читатель не может редактировать (US-03)

| Шаг | Действие                                                                              | Ожидаемый результат                                           |   |
|-----|---------------------------------------------------------------------------------------|---------------------------------------------------------------|---|
| 1   | Авторизоваться как пользователь с ролью «reader»                                      | Успешный вход                                                 |   |
| 2   | Открыть любой документ                                                                | Кнопка «Редактировать» отсутствует на странице                |   |
| 3   | Попытаться вручную перейти по URL /edit/123 (или отправить PUT на /api/documents/123) | Сервер возвращает HTTP 403 Forbidden, страница не открывается |   |
|     |                                                                                       |                                                               |   |

Дополнительно (позитивный для редактора):

| Шаг | Действие                                        | Ожидаемый результат                                        |   |
|-----|-------------------------------------------------|------------------------------------------------------------|---|
| 4   | Выйти и зайти как пользователь с ролью «editor» | Кнопка «Редактировать» появляется, редактирование возможно |   |
|     |                                                 |                                                            |   |

**5. TC-05:** Просмотр счётчика и списка популярных документов (US-04)

| Шаг | Действие                                               | Ожидаемый результат                                                                               |   |
|-----|--------------------------------------------------------|---------------------------------------------------------------------------------------------------|---|
| 1   | Авторизоваться как редактор                            | Успешный вход                                                                                     |   |
| 2   | Открыть документ «Инструкция по работе с ЭДО» (id=10)  | На странице документа отображается счётчик просмотров (например, «Просмотров: 42»)                |   |
| 3   | Перейти в админ-панель → раздел «Популярные документы» | Отображается список 5 документов с наибольшим количеством просмотров, отсортированный по убыванию |   |
| 4   | Нажать на один из документов в списке                  | Открывается карточка документа                                                                    |   |
|     |                                                        |                                                                                                   |   |

Негативный вариант TC-05a (без просмотров):

| Шаг | Действие                                        | Ожидаемый результат                                                                  |   |
|-----|-------------------------------------------------|--------------------------------------------------------------------------------------|---|
| 1   | Создать новый документ (никаких просмотров нет) | Счётчик просмотров = 0                                                               |   |
| 2   | Список популярных документов обновляется        | Новый документ не появляется в списке популярных, пока не получит хотя бы 1 просмотр |   |
|     |                                                 |                                                                               

**6. TC-06:** Создание нового документа (дополнительный сценарий для автора)

| Шаг | Действие                                                                                | Ожидаемый результат                                                                                                                   |   |
|-----|-----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|---|
| 1   | Авторизоваться как пользователь с ролью «author»                                        | Успешный вход                                                                                                                         |   |
| 2   | Нажать кнопку «Создать документ» на главной странице                                    | Открывается форма создания: поля «Заголовок», «Содержимое», «Теги»                                                                    |   |
| 3   | Заполнить заголовок «Регламент работы с КЭП», содержимое (Markdown), добавить тег «КЭП» | Все поля валидны, кнопка «Сохранить как черновик» активна                                                                             |   |
| 4   | Нажать «Сохранить как черновик»                                                         | Система создаёт запись в таблице documents, создаёт первую версию (version_number=1) со статусом draft, автором текущего пользователя |   |
| 5   | Открыть историю документа                                                               | Видна версия 1, статус draft, нет кнопки «Утвердить» (только у редактора)                                                             |   |
|     |                                                                                         |                                                                                                                                       |   |

Негативный вариант TC-06a:

| Шаг | Действие                                 | Ожидаемый результат                                                      |   |
|-----|------------------------------------------|--------------------------------------------------------------------------|---|
| 1   | Не заполнять заголовок (оставить пустым) | Кнопка сохранения неактивна, появляется подсказка «Заголовок обязателен» |   |
|     |                                          |                                                                          |   |

**7. TC-07:** Утверждение версии редактором (дополнение к TC-01)

| Шаг | Действие                                  | Ожидаемый результат                                                                                           |   |
|-----|-------------------------------------------|---------------------------------------------------------------------------------------------------------------|---|
| 1   | Авторизоваться как редактор               | Успешный вход                                                                                                 |   |
| 2   | Найти документ с версией в статусе review | На странице документа рядом с версией есть кнопка «Approve» или «Отклонить»                                   |   |
| 3   | Нажать «Approve»                          | Статус версии меняется на approved, поле current_version_id в таблице documents обновляется на ID этой версии |   |
| 4   | Открыть документ как читатель             | Отображается утверждённая версия (с новым содержимым)                                                         |   |
|     |                                           |                                                                                                               |   |

Вариант «Отклонить»:

| Шаг | Действие        | Ожидаемый результат                                                                                 |   |
|-----|-----------------|-----------------------------------------------------------------------------------------------------|---|
| 3`  | Нажать «Reject» | Статус версии становится archived, текущая версия документа не меняется, автор получает уведомление |   |
|     |                 |                                                                                                     |   |
