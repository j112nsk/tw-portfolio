# СИСТЕМА УЧЁТА ОБРАЩЕНИЙ
## Техническое задание

### 1. ВВЕДЕНИЕ
Настоящее техническое задание (ТЗ) разработано на создание веб-программы для регистрации, хранения и анализа обращений пользователей в службу технической поддержки компании.
ТЗ определяет цели, назначение, требования к программному обеспечению и порядок приёмки.

### 2. НАЗНАЧЕНИЕ РАЗРАБОТКИ
Программа предназначена для регистрации и учёта обращений пользователей в службу технической поддержки.
Программа применяется специалистами службы поддержки и руководителями для анализа обращений.

### 3. ТРЕБОВАНИЯ К ПРОГРАММЕ
Программа должна обеспечивать возможность выполнения перечисленных ниже функций:

1)	аутентификацию пользователя с использованием логина и пароля;
2)	хранение истории обращений;
3)	доступ руководителя отдела к статистической информации по обращениям;
4)	создание и редактирование обращений специалистами службы поддержки;
5)	фильтрацию и поиск обращений по дате, статусу и пользователю;
6)	время обработки обращения не более 2 с при нагрузке до 100 обращений одновременно;
7)	резервное копирование базы данных не реже одного раза в сутки;
8)	разграничение прав доступа пользователей (специалист/руководитель/администратор).

### 4. ТРЕБОВАНИЯ К ПРОГРАММНОЙ ДОКУМЕНТАЦИИ
Состав программной документации должен включать в себя:

1)	руководство пользователя;
2)	руководство администратора;
3)	техническую документацию для сопровождения системы;
4)	описание программы.

### 5. СТАДИИ РАЗРАБОТКИ
Разработка должна быть проведена в четыре стадии:

1)	разработка технического задания;
2)	рабочее проектирование;
3)	тестирование;
3)	внедрение.

### 6. ПОРЯДОК КОНТРОЛЯ И ПРИЕМКИ
Контроль выполнения требований осуществляется на каждом этапе разработки.
Приёмка системы проводится комиссией заказчика по результатам тестирования.
Система считается принятой, если выполнены все требования раздела 3 ТЗ.
