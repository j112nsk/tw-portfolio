## 1. Назначение документа

Документ содержит историю версий продукта MeteoHub. В нем фиксируются новые возможности, изменения в архитектуре и исправления ошибок.

Формат версий: `X.Y.Z`, где:
*   `X` — мажорная версия (значительные изменения архитектуры или интерфейса).
*   `Y` — минорная версия (новая функциональность).
*   `Z` — патч (исправление ошибок, косметические правки).

## 3. Планы на будущее (Roadmap)

В версии 2.0 планируется:
1.  **Аутентификация:** Добавление JWT-токенов для защиты API (Rate Limiting).
2.  **База данных для избранного:** Перенос `favorites.json` в PostgreSQL для синхронизации между устройствами.
3.  **Расширение аналитики:** Добавление графиков трендов (сравнение текущего прогноза с историей за 5 лет).
4.  **Docker:** Контейнеризация приложения (`docker-compose.yml`) для развертывания на Linux-серверах.
