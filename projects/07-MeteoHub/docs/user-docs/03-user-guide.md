## 1. Назначение документа

Руководство описывает работу с веб-интерфейсом MeteoHub. Вы научитесь искать населённые пункты, сохранять их в избранное, просматривать текущую погоду, прогнозы и аналитику за неделю.

## 2. Начало работы

Для запуска интерфейса дважды кликните по файлу **`run-all.bat`** в корневой папке проекта. Откроются два окна: одно для сервера API, другое — для самого дашборда. Если браузер не открылся автоматически, перейдите по адресу `http://localhost:8501`.

Интерфейс состоит из двух частей:
*   **Левая панель (боковая):** настройки, поиск городов и избранное.
*   **Основная область:** три вкладки с данными: «Текущая погода», «Прогноз и графики», «Аналитика».

## 3. Поиск населённого пункта

Вы можете найти любой город, посёлок или село, поддерживаемое картами OpenStreetMap.

1. В левой панели в поле **«Поиск населённого пункта»** введите название (например, «Томск»).
2. Нажмите **Enter** на клавиатуре или кликните по кнопке **«🔍 Найти»**.
3. Если название неоднозначное (например, «Москва»), ниже появится выпадающий список с вариантами. Выберите нужный (например, *«Москва, Россия»* или *«Москва, США»*). Дашборд автоматически обновится.

## 4. Избранное

Чтобы не искать любимые города каждый раз, добавьте их в избранное.

*   **Добавление:** после поиска нужного города нажмите на звездочку **«⭐»** рядом с его названием. В левой панели появится блок «Избранное».
*   **Ограничение:** можно сохранить до 5 городов.
*   **Переход:** просто кликните по названию города в списке избранного (оно работает как ссылка). Дашборд перестроится.
*   **Переименование:** нажмите на иконку карандаша **«✏️»**, введите короткое имя (например, «Дом» или «Работа») и нажмите «Сохранить».
*   **Удаление:** нажмите на иконку корзины **«🗑️»**.

## 5. Вкладка «Текущая погода»

Здесь отображаются текущие метеорологические данные на момент запроса:
*   **Метрики:** температура (°C), скорость ветра (м/с), влажность (%), атмосферное давление (мм рт. ст.).
*   **Детали:** текстовое описание состояния (например, «Переменная облачность»), количество осадков за следующий час, процент облачности.
*   Внизу указано время наблюдения и **часовой пояс** выбранного населённого пункта.

## 6. Вкладка «Прогноз и графики»

На этой вкладке представлены визуализации прогноза погоды.

### 6.1. График температуры
Линейный график с цветовой градацией. Цвет точек зависит от температуры:
*   **Синий** — морозная погода.
*   **Зелёный/Белый** — около 0 °C.
*   **Красный** — жаркая погода.
*   По оси X откладывается **локальное время** выбранного города (учитывается часовой пояс).

### 6.2. Осадки по часам
Столбчатая диаграмма, показывающая количество осадков (мм) в каждый час.

### 6.3. Роза ветров
Круговая диаграмма, показывающая преобладающие направления ветра. Буквы по кругу означают стороны света (С, СВ, В и т.д.). Длина лепестков показывает максимальную скорость ветра (до 9 м/с).

### 6.4. Сводка по дням
Внизу расположена таблица с агрегированными данными по каждому дню: максимальная и минимальная температура, сумма осадков, максимальный ветер и описание погоды.

## 7. Вкладка «Аналитика»

Здесь выводятся сводные данные за выбранный период (по умолчанию 7 дней). Плашки подсвечены разными цветами для удобства:
*   🔴 **Красная плашка** — Самый тёплый день (с указанием даты и температуры).
*   🔵 **Синяя плашка** — Самый холодный день.
*   🟢 **Зелёная плашка** — Самый дождливый день.
*   🟡 **Жёлтая плашка** — Самый ветреный день.

Если вы измените ползунок «Дней прогноза» в левой панели, аналитика пересчитается для нового периода.

## 8. Типичные ограничения

*   **Время истории:** для запроса исторических данных через API нужно указывать прошедшие даты (архив обновляется с задержкой в несколько дней).
*   **Геокодинг:** если город не находится, попробуйте уточнить запрос (например, добавить область или страну).
*   **Лимиты API:** при очень частых запросах поиска геокодер Nominatim может временно блокировать запросы (не более 1 запроса в секунду).
