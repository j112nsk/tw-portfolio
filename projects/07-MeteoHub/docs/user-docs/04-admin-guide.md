## 1. Назначение документа

Инструкция по развертыванию проекта MeteoHub на локальном компьютере или сервере под управлением Windows 10/11. Документ описывает установку необходимого ПО, настройку базы данных, конфигурацию окружения и запуск приложения.

## 2. Системные требования

Для стабильной работы приложения требуется:
*   **ОС:** Windows 10 или 11 (64-bit). Инструкция также подходит для Linux/macOS с адаптацией команд.
*   **Python:** версия 3.14 или выше.
*   **PostgreSQL:** версия 15 или выше.
*   **Свободное место на диске:** ~500 МБ (в основном для виртуального окружения и библиотек).
*   **Интернет:** требуется для установки зависимостей и запросов к внешним API (MET Norway, Open-Meteo, Nominatim).

## 3. Подготовка программного обеспечения

### 3.1. Установка Python
1. Скачайте установщик с официального сайта [python.org](https://www.python.org/downloads/).
2. Запустите установщик. **Обязательно** отметьте галочку **«Add Python to PATH»** в самом низу первого экрана.
3. Нажмите «Install Now» и дождитесь окончания установки.
4. Проверьте установку в командной строке: `python --version`.

### 3.2. Установка PostgreSQL
1. Скачайте установщик с [официального сайта](https://www.postgresql.org/download/windows/).
2. Запустите установщик, оставляя все настройки по умолчанию (порт `5432`).
3. **Важно:** придумайте и запишите пароль для суперпользователя `postgres`. Он понадобится для создания базы данных.
4. По завершении установки убедитесь, что в системе доступна утилита `psql` (проверьте в новом окне терминала: `psql --version`).

## 4. Развертывание проекта

1. Откройте терминал (PowerShell или CMD) в папке с проектом (например, `E:\GIT\tw-portfolio\projects\07-MeteoHub`).
2. Создайте виртуальное окружение:
   ```cmd
   python -m venv .venv
   ```
3. Активируйте его:
   ```cmd
   .venv\Scripts\activate
   ```
4. Установите все зависимости:
   ```cmd
   pip install -r requirements.txt
   ```

## 5. Настройка базы данных

1. Подключитесь к PostgreSQL под суперпользователем:
   ```cmd
   psql -U postgres
   ```
   *(Введите пароль, который задали при установке).*

2. Выполните SQL-команды для создания пользователя и базы данных:
   ```sql
   CREATE USER meteohub_app WITH PASSWORD 'ПридумайтеНадежныйПароль';
   CREATE DATABASE meteohub OWNER meteohub_app;
   GRANT ALL PRIVILEGES ON DATABASE meteohub TO meteohub_app;
   \q
   ```

## 6. Настройка переменных окружения

1. В корне проекта найдите файл `.env.example`.
2. Скопируйте его и переименуйте в `.env` (командой `copy .env.example .env` или вручную).
3. Откройте `.env` в любом текстовом редакторе (например, VS Code или Блокнот).
4. Впишите пароль, который вы задали для пользователя `meteohub_app` в переменную `PGPASSWORD`. Остальные настройки можно оставить по умолчанию.

Пример содержимого `.env`:
```dotenv
PGHOST=localhost
PGPORT=5432
PGDATABASE=meteohub
PGUSER=meteohub_app
PGPASSWORD=ПридумайтеНадежныйПароль
```

## 7. Применение миграций

Разверните структуру таблиц в базе данных. Выполните в терминале (из корня проекта):
```cmd
python -m db.migrate
```
В случае успеха в консоли появится сообщение `applied: 001_create_schema.sql` и `Готово`.

## 8. Запуск приложения

Для запуска предусмотрены готовые bat-файлы:
1. **`run-all.bat`** — запускает сразу и API, и UI в двух отдельных окнах. Это рекомендуемый способ.
2. **`run-api.bat`** — запускает только бэкенд (доступен по адресу `http://127.0.0.1:8000/docs`).
3. **`run-ui.bat`** — запускает только интерфейс (доступен по адресу `http://127.0.0.1:8501`).

Просто дважды кликните по нужному файлу. Если консоль мигнула и закрылась, запустите файл из терминала, чтобы увидеть текст ошибки.

## 9. Устранение неполадок

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| `ModuleNotFoundError` при запуске | Не активировано виртуальное окружение или не установлены зависимости. | Выполните `.venv\Scripts\activate` и `pip install -r requirements.txt`. |
| Ошибка аутентификации в БД | Неверный пароль в `.env`. | Проверьте переменную `PGPASSWORD` в файле `.env`. |
| Порт 8000 или 8501 занят | Другое приложение использует этот порт. | Закройте приложение или измените порт в `run-api.bat` и `run-ui.bat`. |
| «Кракозябры» в консоли bat-файлов | Проблема с кодировкой Windows. | В коде `.bat` файлов уже прописана команда `chcp 65001 >nul`. Если не помогает, смените шрифт консоли на `Consolas` или `Lucida Console`. |
| Кэш возвращает старые данные | Изменились единицы измерения или логика. | Очистите кэш: `psql -U meteohub_app -h localhost -d meteohub -c "truncate geocode_cache, weather_cache, weather_daily;"` |
| UI не обновляет данные после смены города | Баг кэширования Streamlit. | Нажмите `R` в правом верхнем углу интерфейса или `Ctrl+F5` в браузере. |
