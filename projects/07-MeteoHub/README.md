# MeteoHub

REST API и дашборд для получения текущей погоды, прогноза и исторических
данных через открытый API [Open-Meteo](https://open-meteo.com/).

Проект выполнен как портфолио-кейс по двум профессиям:
**системный / бизнес-аналитик** и **технический писатель**.

Документация проекта следует [общему стайлгайду портфолио](../../docs/01-style-guide.md).
