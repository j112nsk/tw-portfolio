# User Stories с критериями приемки

**1. US-01: Поиск документа**

Как читатель, я хочу найти документ по ключевому слову или тегу, чтобы быстро получить инструкцию.

**Acceptance Criteria:**

- Поле ввода поиска на главной странице.

- Результаты поиска отображаются за <1 секунды.

- При клике на результат открывается карточка документа.

**2. US-02: Создание версии**

Как автор, я хочу отредактировать существующий документ и сохранить его как новую версию, чтобы не потерять историю изменений.

**AC:**

- При редактировании старая версия остаётся доступной в истории.

- Новая версия получает номер (v1, v2…).

- Только редактор может сделать новую версию основной (approved).

**3. US-03: Ролевое ограничение**

Как редактор, я хочу запретить обычным читателям редактировать документы.

**AC:**

- Пользователь с ролью «читатель» не видит кнопок «Редактировать» и «Удалить».

- При попытке прямого GET на /edit/{id} возвращается 403 Forbidden.

**4. US-04: Аналитика просмотров**

Как редактор, я хочу видеть сколько раз каждый документ был просмотрен, чтобы понимать его востребованность.

**AC:**

- На странице документа отображается счётчик просмотров.

- В админ-панели есть список самых популярных документов.
