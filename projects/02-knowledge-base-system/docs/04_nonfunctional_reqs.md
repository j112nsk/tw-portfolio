# Нефункциональные требования

**Производительность:**

- Поиск среди 500 документов – ответ < 1 с.

- Открытие документа (с загрузкой контента) – < 0.5 с.

**Надёжность:**

- Автоматическое резервное копирование раз в сутки.

- Отсутствие потери данных при внезапном отключении БД (журнал транзакций).

**Безопасность:**

- HTTPS на всех страницах.

- Ролевая проверка на серверной стороне (не только UI).

- Логирование всех изменений документов (кто, когда, что изменил).

**Удобство использования:**

- Интерфейс адаптивный (можно читать с телефона).

- Поддержка поиска с опечатками.

- Максимум 2 клика до любого документа из раздела «Часто используемые».

**Масштабируемость (на будущее):**

- Возможность горизонтального масштабирования сервера при росте до 1000 пользователей.
