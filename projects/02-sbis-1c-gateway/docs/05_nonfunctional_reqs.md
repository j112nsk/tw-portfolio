# Нефункциональные требования

**- Производительность:**

   - Обработка 200 документов в час.

   - Время ответа шлюза для 1С (синхронная валидация) < 500 мс.

   - Очередь позволяет накапливать до 10 000 задач.

**- Надёжность:**

   - При недоступности СБИС документы сохраняются в очереди (persistent) и отправляются позже.

   - Механизм повторных попыток с exponential backoff (3 попытки, интервалы 1, 5, 15 минут).

   - Логирование всех входящих/исходящих запросов.

**- Безопасность:**

   - Аутентификация шлюза в СБИС по сертификату или API-ключу.

   - Аутентификация 1С к шлюзу по токену (Bearer).

   - Все HTTPS.

   - Подпись документов КЭП на стороне 1С, шлюз не хранит закрытые ключи.

**- Мониторинг:**

   - Метрики: количество отправленных/неудачных документов, время ответа СБИС.

   - Алёрты при 5% ошибок за час.
