# Интеграционный шлюз между 1С и СБИС (ЭДО)

**Роль проекта:** Демонстрация навыков системного анализа в интеграционных проектах на основе реального опыта (автоматизация выгрузки 200+ документов, интеграция СБИС с 1С).

**Тип**: демонстрационный кейс на основе реального опыта

## Проблема и решение
Ручной ввод первичных документов из 1С в СБИС и обратно занимал 20+ часов в месяц. Шлюз автоматизирует обмен: 1С отправляет документы через REST API, шлюз преобразует форматы, маршрутизирует в СБИС и уведомляет о статусах. Для входящих документов – webhook + очередь.

## Архитектура (кратко)
- Шлюз – синхронный REST API для 1С, асинхронная обработка через очередь (RabbitMQ/Redis)
- Хранилище – PostgreSQL для логов, статусов, очереди
- Взаимодействие с СБИС – по их SOAP/XML API
