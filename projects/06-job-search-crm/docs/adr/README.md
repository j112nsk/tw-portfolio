# Записи архитектурных решений (ADR)

ADR фиксирует значимое решение: контекст, рассмотренные варианты, выбор и последствия.
Решения в рамках требований (D1, D2, …) ведутся в документе
[Vision & Scope](../requirements/01-vision-and-scope.md); в ADR выносятся решения, которые
меняют границы проекта или технологическую основу.
