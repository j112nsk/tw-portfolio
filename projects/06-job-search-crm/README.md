# Job Search CRM

Личная CRM для поиска работы по нескольким направлениям: учёт процессов, дошедших до интервью или
тестового задания, история этапов, напоминания и аналитика воронки.

Проект выполнен как портфолио-кейс по двум профессиям:
**системный / бизнес-аналитик** и **технический писатель**.

## Статус

**MVP выпущен** (релиз 1.0.1, 16.10.2026). Приложение и дашборд работают: создание процесса, список с фильтрами, карточка с действиями, профиль навыков, напоминания и аналитический дашборд. Документация: руководство администратора, руководство пользователя, FAQ, глоссарий, стайлгайд, журнал изменений. BPMN v2.x — в Mermaid.

Историю версий продукта см. в [журнале изменений](docs/user-docs/05-changelog.md).

## Стек

PostgreSQL · Python · Streamlit · Mermaid / draw.io · Git

## Запуск

Быстрый способ — bat-файлы в корне проекта:

- `run-demo.bat` — запуск приложения с **демонстрационной** базой (синтетические данные);
- `run-work.bat` — запуск с **рабочей** базой.

Двойной клик — приложение откроется в браузере. Ярлыки на рабочий стол: правый клик по файлу → **Отправить → Рабочий стол (создать ярлык)**.

Полная инструкция по установке на чистой Windows 10/11 — в [Руководстве администратора](docs/user-docs/01-admin-guide.md).
