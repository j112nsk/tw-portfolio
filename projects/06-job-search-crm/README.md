# Job Search CRM

Личная CRM для поиска работы: учёт вакансий, откликов и воронки + аналитика рынка.

Проект выполнен как кейс системного аналитика: от требований и моделирования процессов
до проектирования БД, SQL-аналитики и работающего прототипа.

## Статус

🚧 В разработке. Текущий этап: 0 — подготовка окружения и структуры проекта.

## Стек

PostgreSQL · Python · Streamlit · Mermaid / draw.io · Git

## Структура проекта

| Папка | Содержимое |
|-------|------------|
| `docs/` | Требования, процессы (BPMN), модель данных, ADR |
| `db/` | DDL-схема, демо-данные, аналитические SQL-запросы |
| `app/` | Приложение на Streamlit |
| `tests/` | Тесты и тест-кейсы |
