# Job Search CRM

Личная CRM для поиска работы по нескольким направлениям: учёт процессов, дошедших до интервью или
тестового задания, история этапов, напоминания и аналитика воронки.

Проект выполнен как портфолио-кейс по двум профессиям:
**системный / бизнес-аналитик** и **технический писатель**.

## Статус

В разработке. Текущий этап: база данных v2.0 (миграции и смоук-тест написаны, проверяются на
PostgreSQL). **Готовность до MVP: ≈ 30%.**

MVP — первая рабочая версия: все истории с приоритетом Must (14 из 20) работают в приложении,
есть минимальная документация. Процент — оценка по весам этапов, обновляется вместе с этим
файлом.

| Этап | Вес | Готово |
|------|-----|--------|
| Требования, процессы, ADR | 20% | 20% |
| BPMN-диаграммы под версию 2.x | 5% | 0% |
| Модель данных (логическая и физическая) | 10% | 8% |
| База данных: миграции, смоук-тест, демо-данные | 10% | 2% |
| Аналитические SQL-запросы | 10% | 0% |
| Приложение: ввод, список, этапы, тестовые, закрытие, напоминания, навыки | 25% | 0% |
| Дашборд: воронка, источники и каналы | 10% | 0% |
| Документация: руководство, быстрый старт, FAQ, глоссарий, стайлгайд | 10% | 0% |
| **Итого** | **100%** | **≈ 30%** |

## Что демонстрирует проект

| Направление | Артефакты |
|-------------|-----------|
| Системный / бизнес-аналитик | Vision & Scope, бизнес-вопросы, пользовательские истории и критерии приёмки, BPMN (AS-IS / TO-BE), статусная модель, ER-диаграмма, DDL и аналитические SQL-запросы, ADR, реестр рисков, тест-кейсы |
| Технический писатель | Руководство пользователя, быстрый старт, FAQ, глоссарий, стайлгайд, журнал изменений, README, документация по структуре БД |

## Стек

PostgreSQL · Python · Streamlit · Mermaid / draw.io · Git

## Структура проекта

| Папка | Содержимое |
|-------|------------|
| `docs/requirements/` | Vision & Scope, пользовательские истории |
| `docs/process/` | AS-IS, TO-BE, статусная модель, BPMN-диаграммы |
| `docs/adr/` | Записи архитектурных решений |
| `docs/data-model/` | Логическая и физическая модели данных |
| `docs/user-docs/` | Руководство пользователя, быстрый старт, FAQ (будут добавлены) |
| `docs/style-guide/` | Стайлгайд и глоссарий (будут добавлены) |
| `db/schema/` | SQL-миграции: схема, справочники, триггеры |
| `db/queries/` | Аналитические и проверочные SQL-запросы |
| `db/seed/` | Демонстрационные данные |
| `db/` | Скрипты подключения и применения миграций (`connection.py`, `migrate.py`) |
| `app/` | Приложение на Streamlit |
| `tests/` | Дымовая проверка базы и тест-кейсы |
