# Job Search CRM

Личная CRM для поиска работы по нескольким направлениям: учёт вакансий, откликов,
версий резюме и воронки + аналитика рынка.

Проект выполнен как портфолио-кейс по двум профессиям:
**системный / бизнес-аналитик** и **технический писатель**.

## Статус

В разработке. Текущий этап: 1 — доработка процесса TO-BE и статусной модели (Vision & Scope v1.2 и AS-IS утверждены).

## Что демонстрирует проект

| Направление | Артефакты |
|-------------|-----------|
| Системный / бизнес-аналитик | Vision & Scope, бизнес-вопросы, user stories и критерии приёмки, BPMN (AS-IS / TO-BE), статусная модель, ER-диаграмма, DDL и аналитические SQL-запросы, ADR, реестр рисков, тест-кейсы |
| Технический писатель | Руководство пользователя, быстрый старт, FAQ, глоссарий, стайлгайд, журнал изменений, README, документация по структуре БД |

## Стек

PostgreSQL · Python · Streamlit · Mermaid / draw.io · Git

## Структура проекта

| Папка | Содержимое |
|-------|------------|
| `docs/requirements/` | Требования: Vision & Scope, user stories |
| `docs/process/` | Бизнес-процессы (BPMN) |
| `docs/data-model/` | Модель данных, словарь данных |
| `docs/adr/` | Записи архитектурных решений |
| `docs/user-docs/` | Руководство пользователя, быстрый старт, FAQ |
| `docs/style-guide/` | Стайлгайд и глоссарий |
| `db/` | DDL-схема, демо-данные, аналитические SQL-запросы |
| `app/` | Приложение на Streamlit |
| `tests/` | Тесты и тест-кейсы |
