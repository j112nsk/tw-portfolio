# Модели данных (JSON и XML)

## 1. Внутренний JSON для исходящего документа (как 1С отправляет шлюзу)

``` json
{
  "documentType": "UPD",
  "receiverInn": "7701234567",
  "receiverName": "ООО Ромашка",
  "date": "2025-03-15",
  "number": "УПД-42",
  "items": [
    {
      "product": "Ноутбук",
      "quantity": 5,
      "price": 50000,
      "taxRate": 20
    }
  ],
  "total": 300000,
  "signature": "base64..."
}
```
## 2. Формат XML для отправки в СБИС (пример фрагмента)

``` xml
<Документ xmlns="http://sbis.ru/ЭДО/УПД">
  <СведенияПродавца>
    <ИНН>7712345678</ИНН>
  </СведенияПродавца>
  <СведенияПокупателя>
    <ИНН>7701234567</ИНН>
  </СведенияПокупателя>
  <Содержание>
    <Товар>
      <Наименование>Ноутбук</Наименование>
      <Количество>5</Количество>
      <Цена>50000</Цена>
    </Товар>
  </Содержание>
</Документ>
```
